v0.6 默认入口改为“提供材料 → 助教分析 → 按提示补充”。用户可上传或粘贴文本材料，问题描述选填；模式、模型开关、拓扑JSON与绑定操作从首页移出。原专业界面保留在 /workbench 供队友开发。

v0.5 保留 OSPF 专用检查，同时新增开放网络排查。开放模式不采用故障类型枚举：模型根据问题自主选择材料读取和知识检索，提交有原文引用的假设，并请求补充证据；LangGraph 保存状态，下一次同会话输入恢复后依据新材料继续分析。

材料以文本为入口，不要求先被 VRP 解析器识别。工具为 read_source、retrieve_reference、compare_materials、check_submitted_pings、submit_hypotheses；分别完成读取原始材料、检索参考、比较前后材料、核对上传Ping统计、提交分析。引用使用材料编号与行号，本轮读过且逐字匹配即可，不额外维护指纹。运行输出继续复用已有配置绑定机制，避免误用旧观测。

模型结论由原文依据、推断和补充请求组成。开放模式当前负责分析与继续取证，OSPF 工具负责已支持范围的确定性检查。后续增加验证工具时，直接接在现有流程上，不必把所有知识编码成故障规则。
