# v0.4 当前进度与后续安排

## 本轮完成

DeepSeek Flash 已通过真实接口验证。LangGraph 可以让模型选择下一条待执行链路，本地工具实际检查后，解释模型读取链路、运行复测与教学知识证据。已完成区域错误 → 路由缺失 → 提交观测通过的同会话流程，保留调用参数、工具返回、耗时与用量。

网页支持模型状态、解释、证据工具详情与报告导出。一级解释会隐藏原配置行及具体参数；模型未成功读取证据时继续使用本地提示。余额不足、认证失败、限流、超时与无效响应有明确失败类型，不自动重试，不改写规则诊断状态。

实际模型调用使用项目自带合成网络数据，尚无实机准确率或教学效果结论。当前不是任意工具自主规划：链路检查覆盖范围及复测要求仍由本地流程明确约束。
