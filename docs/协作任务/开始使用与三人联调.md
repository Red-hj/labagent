## 本地准备

同步 `main`，双击 `setup.cmd` 安装依赖，各自在项目根目录配置 `.env`，再双击 `start.cmd`。本地访问 `http://127.0.0.1:8765/`；在线协作使用同一个网站地址和现有团队口令。

## 共同验收

选择同一真实案例：导入课程资料并试查，上传故障材料，查看诊断和原文引用，核对网络路径，分发检查并补充复测，刷新恢复会话，最后导出报告。

开发前同步主分支，个人分支修改，通过 PR 合并；共同页面或接口先说明范围。每次交付附复现步骤和实际结果，运行记录放 `runtime/`。密钥和原始私有评测材料保留在本地；模型配置持有人可执行评测后共享预测文件。重要会话和导入资料及时下载工作区备份。
