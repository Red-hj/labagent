# 付雨航：实验数据与评测

基线：v0.18.0。两例 FRRouting 实测与首轮 60 例三组评测已完成。全队安排见[开发任务](../后续开发.md)。

## 下一步

1. **课程资料**：首批整理 2～3 份真实指导书或课程笔记，标明来源、版本、章节和资料范围，通过首页资料库试查。
2. **独立题集**：交叉复核已固定的24题公开教材基线，补充真实中文课程问题；题目与原文标注分文件，用 `scripts/evaluate_course_retrieval.py` 检索和评分（见下方知识库说明）。
3. **真实实验**：补充华为 VRP 或课堂案例，保存同一轮拓扑、配置、故障输出、修复步骤和双向复测；配套截图/录屏标注关键操作。

## 交付与验收

交付资料清单、题目与标注、可复现实验包，以及检索/诊断汇总结果。分析正常案例误报与引用问题；模型输入和人工答案分离，原始私有材料按现有约定保管。

任务：[#4](https://github.com/Red-hj/labagent/issues/4)、[#5](https://github.com/Red-hj/labagent/issues/5)、[#10](https://github.com/Red-hj/labagent/issues/10)。操作见[知识库说明](../知识库使用与接口.md)和[实验复测](../实验环境与复测.md)。
