## 两套固定题的主线复评

在主线 `686ee6d` 使用默认 BM25。两套题各有 19 道可答题、5 道资料不足题，使用原资料、原问题和原行号标注。与上一轮同口径基线逐题对照，新增命中、丢失命中和名次变动均为 0。

| 指标 | 中文题 | 英文课件混合语言题 |
| --- | ---: | ---: |
| Top-1 命中 | 14/19 | 5/19 |
| Top-3 命中 | 16/19 | 7/19 |
| MRR@3 | 0.781 | 0.298 |
| 标注原文覆盖 | 16/20 | 7/20 |
| 资料不足题仍返回候选 | 5/5 | 5/5 |
| 候选正文及引用位置与原文一致 | 72/72 | 70/70 |

中文题有 3 道可答题未进前三，其中 1 道在第 4～10 条、2 道在前十外。混合语言题有 12 道未进前三，其中 4 道没有单条片段完整覆盖任何标注，2 道在第 4～10 条、6 道在前十外。资料不足题的候选返回率只衡量检索，回答是否依据不足须单独检查。

复评时按[知识库说明](../知识库使用与接口.md#中文课程资料-24-题对照)使用各自固定资料包和独立标注，为两套资料分别指定干净的本地资料目录。运行 `evaluate_course_retrieval.py search` 生成预测，再运行 `score --diagnose-misses`。原文、逐题预测和标注按原约定在本地保存。

## 同批三组离线复现

用已授权的本地输入、标签和两组原始预测生成同一张对照表。预测与对应的 `.meta.json` 放在一起即可沿用同批参数检查。以下命令适用于已经恢复项目默认私有输入目录的 60 例基准。

```powershell
python -X utf8 -B scripts/evaluate_b.py reproduce --direct-predictions runtime/saved/direct.jsonl --knowledge-predictions runtime/saved/knowledge.jsonl --output runtime/b-reproduced
```

队友使用独立样例时，再传 `--benchmark-dir` 指向含清单和输入的目录，传 `--labels` 指向对应标签。新目录会生成规则、纯模型、知识增强各自的逐例报告和总对照表。原始预测按本地私有评测目录保管。按同一份清单核对严格匹配、故障定位、正常例误报及缺失响应；实际修复有效率结合设备执行与复测单独计算。

2026-11-28 用 60 例固定基准和 7 例公开配置分别离线复跑。三组共 201 条逐例判定均与原报告一致。另在本机隔离 FRRouting 重跑 lab_02。R2 恢复到 Area 0 后，两端邻居恢复为 Full，远端路由重新进入系统路由表，双向 Ping 均从 0/1 恢复到 5/5。该案例记录一次实际修复，批量有效率仍需逐例执行与复测。
