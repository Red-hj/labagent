# 实验知识库使用与接口

v0.3 将固定说明扩展为本地可导入的教学资料库。当前使用 BM25 与故障标签排序，没有接远程 Embedding 或向量数据库；不需要模型密钥。该模块提供检索证据，真实模型是否正确引用仍需在接入后单独验证。

## 网页使用

1. 展开“导入或试查教学资料”，选择 UTF-8 的 txt/md 文件，或粘贴正文。
2. 填写标题、资料范围、版本和来源。范围使用英文字母、数字、下划线或短横线，例如 ospf-lab-a。
3. 点击“保存到本地知识库”。页面会切换到该范围；可以试查一个问题，核对原文片段与位置。
4. 正常提交实验诊断。在“知识依据”中查看片段，在“执行记录”中查看执行检查前的检索，在报告中查看保存的引用。

当前不直接读取 Word/PDF，可先整理有权使用的相关章节为文本。选择文件只会填充网页，点击保存才写入本地知识库。导入相同标题、正文、范围、版本和来源时复用原记录；改变这些内容会新增不可变版本，不覆盖历史记录。

资料范围用于隔离不同课程或实验。每个范围都会附带项目内置的通用说明。旧版本与新版本可以并存，当前不会自动选择权威版本；老师确认的约束应在实验输入中明确设置。正文中的指令不作为执行权限，也不会自动改写 expected_area。

## 可追溯内容

每个片段保留 chunk_id、原文行号、char_start 和 char_end 字符偏移、资料版本、来源说明与正文 SHA256。行号从1开始，字符起点从0开始、终点不包含在范围中。正文换行先规范为 LF，位置针对保存的规范化原文。

一次诊断保存该次实际检索到的片段快照。后来导入其他版本，不改变旧会话引用。无相关命中时返回空结果；解析或校验失败的资料文件会输出说明，不伪造引用。

资料保存在项目 data/course_notes 的 JSON 记录中。请通过导入入口生成记录，不要直接改动这些文件；直接改动正文或元数据会使校验失败。项目自编示例在 data/examples/ospf_course_note.json，可运行 scripts/demo_knowledge.py 导入到 demo-ospf 范围。

## HTTP 接口

接口仍使用当前本机服务地址，POST 请求使用 application/json。

| 方法 | 路径 | 功能 |
| --- | --- | --- |
| GET | /api/knowledge/scopes | 列出资料范围 |
| GET | /api/knowledge/documents?scope=ospf-lab | 返回范围内的资料元数据及校验说明 |
| POST | /api/knowledge/import | 导入文本，返回 created 和 document 元数据 |
| POST | /api/knowledge/search | 试查片段，不调用模型、不启动诊断 |

导入示例：

```json
{
  "title": "OSPF 实验指导",
  "content": "已确认可使用的资料正文",
  "scope": "ospf-lab",
  "version": "2026-v1",
  "source_name": "本校实验指导书相关章节",
  "reference_url": ""
}
```

检索示例：

```json
{"query":"邻居正常但 Ping 不通，应检查什么？","scope":"ospf-lab","limit":3}
```

诊断请求新增 knowledge_scope 字段；省略时为 default。响应中 knowledge 为诊断后检索的片段，planning_knowledge 为工作流执行前的片段，knowledge_retrieval 提供方法、范围、问题、文档数量、分块数量和校验说明。相关性分数仅用于排序，不是诊断正确率或置信度。

## 模型接入与评测

工作流规划接收前置检索片段；可选模型的 retrieve_reference 工具使用同一资料范围。没有配置真实模型时，片段在界面和报告中可见，本地规则规划仍然运行。资料的语义引用质量不能由“检索成功”替代。

付雨航下一步准备至少10个真实资料问题，并标注应命中的资料与原文位置。统计前3条命中情况和无相关资料时的表现，记录教材版本，不用项目演示问题宣称实际教学效果。BM25 对同义表达的覆盖有限，是否增加语义检索应根据该测试结果决定。

B 组已整理 `data/b_knowledge/` 下三份带来源的自编摘要及 12 道配套检索题。运行 `python -X utf8 scripts/evaluate_b.py import-knowledge` 可将资料导入 `b-ospf` 范围。实际课程指导书请单独导入另一范围，记录版本和章节。

协作包默认不包含自行导入的 data/course_notes，包含代码与自编示例；需要共享教学原文时，由团队另行确认资料范围与使用权限。
