# 实验知识库使用与接口

v0.3 将固定说明扩展为本地可导入的教学资料库。当前使用 BM25 与故障标签排序，没有接远程 Embedding 或向量数据库；不需要模型密钥。该模块提供检索证据，真实模型是否正确引用仍需在接入后单独验证。

## 网页使用

首页从输入区下方“实验资料与说明”打开资料库。可以读取UTF-8的`.txt` / `.md`或粘贴正文，按课程设置范围、版本和来源；保存后先试查，点击片段标题打开原文并高亮，再点击“用于当前排查”。诊断的“参考资料”也可直接查看原文。旧会话继续保留当轮引用。单份文件最多500KB、正文最多150000字；PDF先导出文本再导入。首页默认保持精简，资料库按需打开。

专业工作台保留原入口：

1. 展开“导入或试查教学资料”，选择 UTF-8 的 txt/md 文件，或粘贴正文。
2. 填写标题、资料范围、版本和来源。范围使用英文字母、数字、下划线或短横线，例如 ospf-lab-a。
3. 点击“保存到本地知识库”。页面会切换到该范围；可以试查一个问题，核对原文片段与位置。
4. 正常提交实验诊断。在“知识依据”中查看片段，在“执行记录”中查看执行检查前的检索，在报告中查看保存的引用。

当前不直接读取 Word/PDF，可先整理有权使用的相关章节为文本。选择文件只会填充网页，点击保存才写入本地知识库。导入相同标题、正文、范围、版本和来源时复用原记录；改变这些内容会新增不可变版本，不覆盖历史记录。

资料范围用于隔离不同课程或实验。每个范围都会附带项目内置的通用说明。旧版本与新版本可以并存，当前不会自动选择权威版本；老师确认的约束应在实验输入中明确设置。正文中的指令不作为执行权限，也不会自动改写 expected_area。

## 可追溯内容

每个片段保留 chunk_id、原文行号、char_start 和 char_end 字符偏移、资料版本、来源说明与正文 SHA256。行号从1开始，字符起点从0开始、终点不包含在范围中。正文换行先规范为 LF，位置针对保存的规范化原文。

一次诊断保存该次实际检索到的片段快照。后来导入其他版本，不改变旧会话引用。无相关命中时返回空结果；解析或校验失败的资料文件会输出说明，不伪造引用。

资料默认保存在项目 data/course_notes；设置 LABAGENT_DATA_DIR 后保存在该数据目录的 course_notes 中。请通过导入入口生成 JSON，不要直接改动正文或元数据。项目自编示例在 data/examples/ospf_course_note.json，可运行 scripts/demo_knowledge.py 导入到 demo-ospf 范围。

## HTTP 接口

接口仍使用当前本机服务地址，POST 请求使用 application/json。

| 方法 | 路径 | 功能 |
| --- | --- | --- |
| GET | /api/knowledge/scopes | 列出资料范围 |
| GET | /api/knowledge/documents?scope=ospf-lab | 返回范围内的资料元数据及校验说明 |
| GET | /api/knowledge/documents/{id}?scope=ospf-lab | 返回该范围内不可变的完整原文及行数 |
| POST | /api/knowledge/import | 导入文本，返回 created 和 document 元数据 |
| POST | /api/knowledge/search | 试查片段，不调用模型、不启动诊断 |

导入示例：

```json
{
  "title": "OSPF 实验指导",
  "content": "已确认可使用的资料正文",
  "scope": "ospf-lab",
  "version": "2026-v1",
  "source_name": "本校实验指导书相关章节",
  "reference_url": ""
}
```

检索示例：

```json
{"query":"邻居正常但 Ping 不通，应检查什么？","scope":"ospf-lab","limit":3}
```

诊断请求新增 knowledge_scope 字段；省略时为 default。响应中 knowledge 为诊断后检索的片段，planning_knowledge 为工作流执行前的片段，knowledge_retrieval 提供方法、范围、问题、文档数量、分块数量和校验说明。相关性分数仅用于排序，不是诊断正确率或置信度。

导入Markdown按章节切分，忽略代码围栏内形似标题的命令行；每片段仍最多600字，长章节继续按行拆分。纯文本保持按长度和行边界切分。保存的字符位置和行号用于原文定位，完整资料读取同样遵循范围选择与团队认证。

## 模型接入与评测

工作流规划接收前置检索片段；可选模型的 retrieve_reference 工具使用同一资料范围。没有配置真实模型时，片段在界面和报告中可见，本地规则规划仍然运行。资料的语义引用质量不能由“检索成功”替代。

课程评测统一使用下方 `scripts/evaluate_course_retrieval.py` 的资料包与分开检索、评分流程，无需模型密钥。每轮固定语料并复用线上 BM25 排序；保留原 Top-1/Top-3、分类及语言统计，新增 MRR、标注证据覆盖和资料不足题空结果率。题目、答案与结果放在本地 `runtime/`，输出文件不覆盖旧结果。是否加入语义检索或微调，根据独立题集上的实际问题决定。

B 组已整理 `data/b_knowledge/` 下三份带来源的自编摘要及 12 道配套检索题。运行 `python -X utf8 scripts/evaluate_b.py import-knowledge` 可将资料导入 `b-ospf` 范围。实际课程指导书请单独导入另一范围，记录版本和章节。

协作包默认不包含自行导入的 data/course_notes，包含代码与自编示例；需要共享教学原文时，由团队另行确认资料范围与使用权限。

## B 组独立课程检索基线

题集 `b-course-retrieval-1` 基于三份公开英文教学原文，和 12 道开发用题分开。

| 资料 | 版本及章节 | 许可 |
| --- | --- | --- |
| [NSRC Workshops · OSPF Lab](https://www.nsrc.org/workshops/master/cnd/ospf.html) | 2026-11-17 网页快照，涵盖配置、核对与静态路由迁移 | CC BY-SA 4.0 |
| [UCLouvain · OSPF](https://github.com/cnp3/ebook/blob/5d270364790500fe58283be91329365835a69d66/protocols/routing.rst#L64-L164) | CNP3 第三版，Internet Routing 的 OSPF 小节 | [CC BY-SA 3.0](https://github.com/cnp3/ebook#readme) |
| [UCLouvain · Link-State Routing](https://github.com/cnp3/ebook/blob/5d270364790500fe58283be91329365835a69d66/principles/linkstate.rst#L8-L345) | CNP3 第三版，链路状态路由章节 | [CC BY-SA 3.0](https://github.com/cnp3/ebook#readme) |

导入包记录来源、版本、章节和范围 `b-course-open-v1`。原文转为 Markdown 文本后重新断行，标注指向导入文本中的行号。24 道独立题含 7 道直接问法、8 道同义改写、4 道易混概念和 5 道资料不足题。题目和初版标注在首次检索前固定，由 B 组保管，待队友交叉复核。黄泓钧可以用相同的资料和题目提交其他检索方案的预测，由持有标注的一方评分。

| 本地 BM25 指标 | 结果 |
| --- | --- |
| 可答题首条命中（Top-1） | 5/19 |
| 可答题前三条命中（Top-3） | 7/19 |
| 同义改写题前三条命中 | 1/8 |
| 中文 / 英文可答题前三条命中 | 1/9、6/10 |
| 资料不足题仍返回片段 | 5/5 |
| 返回片段的原文、行号及字符位置一致 | 70/70 |

命中要求同一候选片段完整覆盖至少一项预先标注的支持原文。原文定位一致只检查引用位置。资料不足题仍返回片段说明当前检索会给出词面相关候选，生成答案的拒答表现需要另测。此批资料均为英文，中文题还涉及跨语言检索。复评用同一资料快照及题集，分别报告中英文与无答案题。

取得资料与题目包后，将 `manifest.json`、`questions.json` 和 `materials/` 解压到 `runtime/b-course-v1`。评分人单独恢复 `labels.json`。在项目根目录运行下面的命令可导入、检索和评分，无需模型密钥。

```powershell
$env:LABAGENT_DATA_DIR = 'runtime/b-course-v1/store'
python -X utf8 scripts/evaluate_course_retrieval.py search runtime/b-course-v1 runtime/b-course-v1/bm25-predictions.json
python -X utf8 scripts/evaluate_course_retrieval.py score runtime/b-course-v1 runtime/b-course-v1/bm25-report.json --labels runtime/b-course-v1/labels.json --predictions runtime/b-course-v1/bm25-predictions.json
```

重新执行时将两个输出改用新文件名。也可通过首页导入三份 `materials/`，按 `manifest.json` 填写元数据并试查。其他检索器可保留预测 JSON 的 `version`、`scope`、`method` 和 `predictions` 结构。`predictions` 以题号为键，每题按返回顺序提供 0～3 个片段。片段采用当前检索接口字段，评分会对照导入版本核验原文与偏移。
