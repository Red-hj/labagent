# LabAgent 实验诊断工具

LabAgent 读取截图、配置、日志和实验说明，结合资料检索与工具检查，帮助团队定位问题、修改配置、补充复测并导出报告。

本轮发布 **v0.21.1**：[在线体验](https://labagent-15yh.onrender.com/) · [下一轮开发任务](docs/后续开发.md)

MCP 实验电脑连接入口已部署：在实验电脑运行连接程序，网站选择检查，输出加入当前材料后继续核对。React 对话、材料面板和工具执行状态已接入；AgentArts 已更新至 v9，支持持续分级引导和云端调用已配对实验电脑。配置与接入范围见[接口说明](docs/接口说明.md#持续实验引导与-mcp)。

## 功能亮点

- **看图排查**：粘贴或上传截图，识别文字，引用可定位原图；支持日志和终端录屏回溯。
- **持续对话**：沿同一会话追问、更新材料和复测，支持历史搜索、恢复与删除。
- **个人记忆**：注册个人账号，积累历史问题，保存排查偏好与实验环境；支持编辑、删除、清空和关闭，个人新对话按账号区分。
- **课程知识库 / RAG**：导入课程笔记，按章节检索；正文匹配优先，页面标明仅标题匹配，引用可打开原文并高亮。模型可按需查资料，缺少依据时请求补充。当前采用 BM25 关键词检索。
- **网络地图与协作**：按网关、ARP 和路由解释路径，共享材料、分发检查任务并处理版本冲突。
- **实验目标核对**：同时检查连通性、路由协议和配置要求；已有 FRRouting 实测修复对照。
- **报告与备份**：导出排查报告，下载并恢复包含会话、协作记录和媒体的工作区备份。

## 快速开始

1. 同步仓库，双击 `setup.cmd` 安装依赖。
2. 将 `.env.example` 复制为项目根目录的 `.env`，填写自己的模型配置。
3. 双击 `start.cmd`，打开 [本地首页](http://127.0.0.1:8765/)。专业工具入口为 `/workbench`。
4. 上传材料后开始诊断；课程笔记可点击首页“上传课程资料”，已有资料从“课程资料库”查看。
5. 从右上角“登录 / 记忆”创建个人账号；同一服务端换设备登录可读取自己的记忆和新对话。旧团队记录继续共享，协作排查通过邀请链接访问，个人记忆不用于共享诊断。

接入实验电脑可从网页下载连接包，解压后在 Windows 双击 `connect.cmd`：首次填写 Huawei VRP 设备控制台地址和端口，实际读取接口输出，再输入网页连接码。项目内也可运行 `python scripts/connect_lab.py --setup` 生成配置，`--probe` 实际读取设备，去掉标志后配对。已有 MCP 配置继续兼容。配置方法见[实验电脑连接说明](docs/接口说明.md#内置-huawei-vrp-控制台接入v0211)。

线上团队访问口令沿用现有配置。网站连接 AgentArts v9，由云运行时完成材料诊断。账号、记忆和历史实时保存在服务端 SQLite，并自动备份到免费 Supabase 私有存储，空工作区启动时恢复。页面显示“已保存到云端”后的版本可跨部署恢复；尚未同步的修改仍依赖当前实例。配置方法见[持久化接口说明](docs/接口说明.md#免费云端持久化v0191)。手动全站备份仍需独立维护口令，包含账号与记忆，请由维护人员保管。

## 开发资料

前端对话组件使用 React 19 + TypeScript，源码在 `frontend/src/`。修改组件后运行 `npm ci`、`npm run check:web`、`npm run build:web`；构建后的 `web/react-conversation.js` 随代码提交，Python 网站直接提供静态文件。普通启动继续使用 `start.cmd`。
