连接我的实验电脑

在实验电脑上运行本地连接程序，网站便可读取你选择的设备输出。输出加入当前材料后，继续核对正在做的这一步。

第一次连接

先登录个人账号。实验电脑需已配置本地 MCP 检查工具；生成连接码后，在该电脑的项目目录运行下面的程序，按提示输入连接码。

python scripts/connect_lab.py runtime/mcp.json

连接码5分钟内有效，只在自己的实验电脑输入；重新生成会断开旧连接。本地配置与设备凭据留在电脑上。
