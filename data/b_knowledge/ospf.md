# OSPF 区域和邻接

## 区域一致与实验指定区域
先按拓扑确定同一条互联链路的两个接口，再比较实际参与的 Area。区域不一致是一项协议条件问题；只有实验明确要求 Area 0，才可据此指定哪一端违反实验要求。多区域网络中不同链路使用不同区域并不自动构成故障。

## 进程号与 Router ID
进程号标识本设备内部的 OSPF 进程，对端不需要使用相同编号。Router ID 用来识别参与 OSPF 的路由器；确认 Router ID 时应查看各进程实际使用的标识，不能把进程号或接口 IP 当成 Router ID。

## 接口启用与 network
VRP 的 Area 视图下，network 选择符合地址条件的接口参与 OSPF，也可能采用接口级 ospf enable。若互联接口 IP 不在选择范围内且未直接启用，就应先查接口启用关系，不能凭配置中出现过 ospf 字样就断定邻居会建立。

## Full 状态的适用边界
本实验使用每段两端互连的拓扑，预期邻接达到 Full；多设备共享广播网络中的某些邻居可以停留在 2-Way。应结合网络类型、角色和实验指定的邻接关系判断，不能把所有非 Full 状态一概判故障。
